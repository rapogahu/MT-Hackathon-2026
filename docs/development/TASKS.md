# Небольшие задачи до рабочего сервиса

Это порядок разработки по ТЗ 4.2, не перечень уже начатых работ. Для запуска перенеси **одну** задачу в ACTIVE_TASK и поручай её явно. При необходимости дели строку ещё мельче, сохраняя проверяемый результат.

| ID | Задача | Зависимость | Проверяемый результат |
|---|---|---|---|
| DEV-01 | Регрессионные тесты текущего backend | Работающий справочник | Старые routes/stops/assignments покрыты тестами |
| DEV-02 | Настройки, lifespan и фиксация backend/dev-зависимостей | DEV-01 | Excel-путь конфигурируется, import модуля не читает файл, регрессия проходит |
| DEV-03 | PostgreSQL, SQLAlchemy-модели и Alembic | DEV-02 | Миграция пустой тестовой БД, constraints/индексы и отдельная Session |
| DEV-04 | Импорт history/forecast, нормализация и публикация run | DEV-03 | Валидный файл импортирован атомарно, rollback/повтор проверены |
| DEV-05 | Внешний POST /api/predict | DEV-04 | Три поля на входе, четыре на выходе; порядок, даты, ошибки и один run |
| DEV-06 | GET прогноза, диапазонов, агрегатов, каталога и CSV | DEV-04 | Все представления/экспорт совпадают по ключам одного run |
| DEV-07 | Геометрия и MapService | DEV-06 | Правильные route/trip keys, GeoJSON и честное отсутствие схемы |
| DEV-08 | Frontend: каркас, API-клиент, DAY и KPI | DEV-05/06 | Реальные значения из API, загрузка/ошибка и закреплённый run |
| DEV-09 | MONTH/PERIOD/ALL, суммы и экспорт | DEV-08 | Пользователь получает прогноз произвольного периода ноября–декабря |
| DEV-10 | Карта, остановки/участки и отсутствие геометрии | DEV-07/09 | Географическая навигация не меняет прогноз |

DEV-04 достаточно велик: допускаются отдельные карточки для импорта, нормализации и атомарной активации. Не объединяй все DEV-пункты в одно поручение.

## ML-ветка

| ID | Задача | Зависимость | Проверяемый результат |
|---|---|---|---|
| ML-01 | Labels/raw parser, аудит, сетка и маршрут 5 | Исходные данные | Воспроизводимый target, статусы нулей/пропусков и отчёт |
| ML-02 | Seasonal baselines и временная оценка | ML-01 | Прогноз длинного горизонта без чтения будущих лагов |
| ML-03 | Direct CatBoost, Daily TS, ансамбль и сравнение | ML-02 | Компоненты/веса проверены одинаковыми folds; сохранён metrics.json |
| ML-04 | Финальный forecast, metadata и импортная проверка | ML-03 | Собственные 14 640 прогнозов и артефакт воспроизведения |
| ML-05 | CalendarProvider и geolinking interface | ML-01 | Нет фиктивных внешних признаков, неподходящая геопривязка unavailable |

ML-ветка может выполняться командой параллельно разработке web; это не инструкция автоматически запускать субагентов. Для DEV-04/05 до готовности ML допустимы явно синтетические тестовые fixtures. Они не заменяют реальный прогноз в итоговой приёмке. Самостоятельные YEAR, XLSX и настоящий matcher остаются расширениями после MVP.
