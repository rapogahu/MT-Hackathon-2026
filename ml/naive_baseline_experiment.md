# Naive baseline from raw transactions — 2026-09-25

**Hypothesis:** A fixed weekly boarding profile gives a reproducible first reference for a 61-day forecast.

- **Source data:** `data/raw/train.csv` (8,160,068,959 bytes; modified 2026-09-25 11:57:08 UTC) and `data/raw/test.csv` (2,231,502,820 bytes; modified 2026-09-25 11:55:18 UTC). The `labels_day_*` files are annotations for these sources and were not used in this run.
- **Target and processing:** Count raw rows with `validation_result == 1` by route from `ngpt_route`, calendar date and hour from `tran_date_time`. Retain only `2025-01-01`–`2025-08-31` from train and `2025-09-01`–`2025-10-31` from test. Complete every route/date/hour grid with zero where there are no successful validations.
- **Fit and forecast:** Mean by `(route, weekday, hour)` over the last four complete training weeks, `2025-08-04`–`2025-08-31`, including zero cells. Round to the nearest non-negative integer, with halves up. Generate the full 61-day prediction before opening `test.csv`. No tuning or random seed.
- **Validation:** One temporal holdout, `2025-09-01`–`2025-10-31`; 10 routes × 61 days × 24 hours = 14,640 cells. WAPE is `sum(abs(y - prediction)) / sum(y)` over the full grid; WAPE-score is `max(0, 1 - WAPE)`.
- **Result:** **WAPE 0.209715; WAPE-score 0.790285.**
- **Processed data:** `data/processed/baseline_train_hourly.csv` (58,320 rows; SHA-256 `51c0eeff909392ca6070cfb8c8b2aae8fb04121bf84e7835e1db490afcfd175d`) and `data/processed/baseline_validation_hourly.csv` (14,640 rows; SHA-256 `7fce4c926d53b6b7739ed7ac01e5166d15f85d83a23685152b9e7a4ba21861a6`). Both have unique keys and no missing or negative targets.
- **Reproduction:** From the repository root, run `python ml/src/prepare_baseline_data.py` to create the processed tables when they are absent, then `python ml/src/naive_baseline.py` to evaluate them. The preparation script refuses to overwrite existing tables. Python 3.12.6 and pandas 2.2.3 were used for preparation; the baseline evaluator uses the Python standard library. Base commit: `4af1e18608e088a8a6dca41a35d03c2627536fcc`.

After separating responsibilities, `prepare_baseline_data.py` has SHA-256 `31f736ae6e10c93ebbc3121b399e821ed61930e89bc6aeaff39914e2f266044d` and `naive_baseline.py` has SHA-256 `b6961daf78d1c603a749daf0690bf9905ca63b1d4c1580def5f3cc217d66a037`. - **Conclusion:** The temporal baseline gives a reference score using raw transactions. Its fixed weekly profile cannot adapt to demand shifts during the forecast horizon.
